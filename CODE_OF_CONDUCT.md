# Code of Conduct

CheeseWAF is a security project. We expect everyone to communicate with
respect, assume good faith, and focus criticism on ideas and evidence.

Unacceptable behaviour includes harassment, discrimination, threats,
deliberate disclosure of private information, and security testing against
systems without permission. Maintainers may remove content or restrict
participation when necessary to keep the project safe and constructive.

Report a conduct concern privately to the repository maintainers through the
contact method in [SECURITY.md](SECURITY.md). Please do not include secrets or
unpatched vulnerability details in a public issue.

This code of conduct applies in the repository, its issue tracker, reviews,
and project communication channels.
